# User journeys

## Install and first entry

Open the pilot download instructions, install the signed APK, and open Persian RTL Home. Add a vehicle from the catalog or manually. Open quick add, choose fuel or a recent category, enter the amount and fuel volume where required, and save. Default to the selected vehicle and Tehran date. Show the previous odometer as a reference and leave the new reading blank. Preserve input on validation and save errors. Show success only after the local write commits.

## Review and correct

Open History to find an expense or maintenance event. Edit it or confirm deletion. Home reflects the new monthly total, recent activity, and latest recorded odometer. Use localized errors and readable empty states. Accept Persian, Arabic-Indic, and Latin digits. Use logical RTL alignment and isolate phone numbers and other LTR values. Check larger text, focus, screen-reader labels, and touch targets.

## Set a reminder

Set a due date or odometer threshold and return to Home. Mark the reminder complete or cancel it. Offer date notifications through explicit opt-in. Keep due items visible in the app when permission is declined or Android delays delivery.

## Export and recover

In Settings, choose manual export and a file location. Explain before saving that the driver must retain the file safely and manually export again to include later changes. State that manual file export is not automatic backup. In an empty installation, select a file, validate it, and show a clear success or failure state.

From M5, an invited driver can attach an account and tap **Back up now**. Show the last confirmed upload and explain when newer local changes are missing from it. On an empty installation, authenticate and restore the last acknowledged snapshot. State that this is not live multi-device sync and that records from different devices are not merged. A stale-write warning directs the driver to export the local ledger without replacing the server copy.

## Delete data

From M6, Settings provides separate local erasure and cloud account deletion controls. Explain the scope of each before confirmation and offer export first. Losing connectivity during cloud deletion must not look like confirmation.
